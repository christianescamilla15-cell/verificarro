# ADR 0001 · Registrar las decisiones de arquitectura

- Estado: aceptada · Fecha: 2026-11-19

## Contexto
Las decisiones importantes se pierden en commits y conversaciones.

## Decisión
Cada decisión que cambie la estructura, una dependencia mayor o un contrato se registra como ADR numerado en
`docs/adr/`, con contexto, decisión, alternativas y consecuencias.

## Consecuencias
Quien llegue al repo entiende por qué el sistema es como es, no sólo cómo es.
